# 모각 MOGAK

## 1. 배포 링크
- [서비스 바로가기](https://mogak.kr)

## 2. 기술 스택

### **Framework & Language**
- **Next.js 15 (App Router)**
- **React 18**
- **TypeScript**

### **Styling & UI**
- **Tailwind CSS**
- **React Icons**

### **State Management**
- **Zustand** (전역 상태 관리)
- **React Hook Form** (폼 상태 및 유효성 관리)

### **Data Fetching & Networking**
- **fetch API** (서버 API 연동)
- **WebSocket (STOMP 기반)** – 실시간 채팅 및 데이터 업데이트

### **Utilities**
- **dayjs** (날짜 계산 및 포맷)
- **react-query** (데이터 캐싱)
- **React Pagination Component** (커스텀 Pagination)

### **Build & Config**
- **ESLint + Prettier** (코드 스타일링 및 린팅)
- **PostCSS** (Tailwind 설정)
